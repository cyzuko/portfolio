Web App
DigiFatura

DigiFatura é uma aplicação web de gestão de faturas que simplifica o processo de captura, organização e análise de documentos financeiros.

Utilizando OCR (Reconhecimento Ótico de Caracteres), a aplicação permite capturar automaticamente as informações das faturas através do dispositivo móvel, eliminando a necessidade de introdução manual de dados.

Funcionalidades
  • Captura automática de faturas via OCR no dispositivo móvel
  • Sincronização em tempo real entre dispositivos
  • Dashboard com estatísticas e análise de despesas
  • Sistema de notificações para faturas pendentes
  • Exportação e organização por categorias
Tecnologias
Node.js MySQL REST API OCR Laravel
Web App
EUREKA

EUREKA é uma plataforma de gestão de explicações (aulas particulares) que centraliza a comunicação, o acompanhamento de alunos e a análise de desempenho num único lugar.

Desenhada para professores e centros de explicações, permite gerir horários, comunicar com alunos e acompanhar o progresso de forma intuitiva.

Funcionalidades
  • Gestão de alunos, horários e sessões
  • Grupos de mensagens em tempo real
  • Dashboard com estatísticas de desempenho
  • Sistema de notificações automáticas
  • Sincronização em tempo real entre utilizadores
Tecnologias
Node.js MySQL REST API Laravel WebSockets
