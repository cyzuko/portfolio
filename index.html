Web App
DigiFatura

DigiFatura é uma aplicação web de gestão de faturas que simplifica o processo de captura, organização e análise de documentos financeiros.

Utiliza OCR (Reconhecimento Ótico de Caracteres), a aplicação permite capturar automaticamente as informações das faturas através do dispositivo móvel, eliminando a necessidade de introdução manual de dados.

Funcionalidades
  • Captura automática de faturas via OCR no dispositivo móvel
  • Sincronização em tempo real entre dispositivos
  • Dashboard com estatísticas e análise de despesas
  • Sistema de notificações para faturas pendentes
  • Exportação e organização por categorias
Tecnologias
Node.jsMySQL REST APIOCR Laravel

Web App
EUREKA

EUREKA é uma webapp de gestão de explicações que centraliza a comunicação, o acompanhamento de alunos e a análise de desempenho num único lugar.

Desenhada para centros de explicações, permite gerir horários, comunicar com alunos e acompanhar o progresso de forma intuitiva.

Funcionalidades
  • Gestão de alunos, horários e sessões
  • Grupos de mensagens em tempo real
  • Dashboard com estatísticas das diversas explicações
  • Sistema de notificações automáticas
  • Sincronização em tempo real entre utilizadores
Tecnologias
Node.jsMySQL REST APILaravel WebSockets
